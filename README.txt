GAME HUB - FRONT-END DEMO

Files:
- index.html: page structure
- style.css: responsive dark gaming UI
- app.js: demo interactions and browser storage

How to run:
1. Keep all three files in the same folder.
2. Open index.html in a modern browser.
3. Create an account, then add gamer IDs from Edit profile.

Demo limitations:
- Data is stored in localStorage in the current browser only.
- Accounts are not secure and passwords are not encrypted. Do not use a real/reused password.
- Friend requests, chat, and parties work only among accounts stored in this same browser profile. They do not sync between different devices or browsers.
- To launch for real friends, add a backend (for example Supabase or Firebase) with authentication, database rules, and real-time messaging.
- This is a front-end prototype, not a production-ready social network.
